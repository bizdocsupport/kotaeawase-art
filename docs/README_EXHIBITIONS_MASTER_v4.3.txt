2026-08-21

■ 変更の目的
展覧会情報が以下に分散していた状態を解消しました。
- exhibitions-curated-v4.js（v4カード）
- exhibitions-data.js（旧ガイド／旅先予定）
- exhibition-detail-data.js（記事側の重複メタ情報）
- exhibition-calendar.js（チケット日程）

今後の正本は assets/js/exhibitions-data.js の window.KA_EXHIBITIONS だけです。
会期、会場、画像、公式URL、見どころURL、訪問日、チケット日程は原則ここだけを更新してください。

■ 自動分類
実在の展覧会（kind: exhibition）は日付だけで以下へ移動します。
- start <= 今日 <= end ：「今、会いに行ける。」
- 開幕まで0〜45日     ：「もうすぐ始まる。」
- 開幕まで46〜180日   ：「少し先だけど、覚えておきたい。」
- end < 今日           ：ARCHIVE

trip-guide は開催中一覧から除外し、終了後はARCHIVEへ入ります。
visitDate が過ぎた展覧会は、会期中でも「見てきた記録」としてARCHIVEにも表示します。

■ 重要な修正
- 開催中カードの「最大6件」制限を撤廃。掲載中の8件がすべて表示されます。
- ARCHIVEは旧配列の寄せ集めではなく、KA_EXHIBITIONSのみから生成します。
- チケット日程もKA_EXHIBITIONS.ticketEventsから生成します。
- 展覧会詳細の会期・会場・公式URL・カード画像はKA_EXHIBITIONSを優先します。
- 旧EXHIBITION_GUIDES / TRAVEL_EXHIBITIONS / KA_CURATED_EXHIBITIONSは互換用にマスタから自動生成します。
- 旧ギャラリー11件と展覧会詳細記事11件をすべてマスタへ対応づけ済みです。
- 来日予定13作品で使われている6つの展覧会名もすべてマスタへ対応づけ済みです。
