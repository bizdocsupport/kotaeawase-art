修正内容
- チケット日程メニューをカードDOM内ではなく body 直下の最前面レイヤーに表示

- 同時に開けるメニューを常に1つだけに制限
- 別カードを開くと、先に開いていたメニューを自動で閉じる
- 同じボタンを再クリックすると閉じる
- メニュー外クリック / Esc / スクロール / リサイズで閉じる
- PCはボタン下に表示。下側に空きがなければ上側へ自動配置
- スマホは画面下部のシート表示
- CSS/JSキャッシュバスターを v2.5.0 に更新
