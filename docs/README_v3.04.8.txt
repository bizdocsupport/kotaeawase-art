追加：全作品 01 / 02 / 03 検品ページ
URL: /art/inspection.html

■目的
全301作品の全体・01・02・03を1画面で比較し、明らかにズレているヒントだけを先に抽出するための内部検品ページです。

■主な機能
- 海外 / 日本の絞り込み
- ID / 画家 / 作品名検索
- 全体 + 01 + 02 + 03 の4面同時表示
- 各01/02/03ごとに「ズレを記録」
- 作品単位で「確認済み」
- メモ保存
- ズレあり / 未確認 / 確認済み / データ不足フィルター
- ズレ一覧のクリップボードコピー
- レビューCSV書き出し
- 画像クリックで拡大確認

■レビュー保存について
検品結果は localStorage を使用し、そのブラウザ内だけに保存されます。
サーバーへは送信しません。

■検索エンジン
inspection.html は noindex / nofollow 設定です。
サイトの通常ナビゲーションおよび sitemap には追加していません。
