現代アート「5の型」｜
映え映え系とは？｜「なんかいい」から見ていい

意味がわからなくても、「なんかいい」から始めていい。色、形、配置、リズムのどれに目が止まったかを一つだけ探します。

先に結論

5の型は、見た目そのものを楽しむ型。「意味は？」を急がず、色・形・配置・リズムのうち、自分が反応したものを一つ言葉にします。

現代アートを見ると「何か深い意味を理解しないといけない」と思いがちでした。だから、きれいだと思っても「でもそれだけじゃダメなんだろうな」と勝手に構える。5の型を知って、「よくわからないけど、この色は好き」で始めてもいいとわかったのは、自分にはかなり大きかったです。

1. 映え映え系って何？

5の型は、作品の見た目そのものを楽しむ目的から見る型です。色、形、配置、リズム、反復、素材感。何かの意味を読み取る前に、「どう見えるか」を味わいます。抽象作品だけでなく、具象的な作品でも、構成や色の気持ちよさが前に出るならこの型で見られます。

「映え」という言葉からSNS向けの派手さだけを想像しなくて大丈夫です。静かな色面、ほとんど変化のない形、規則正しい並びでも、「見ること自体」が作品の中心なら5の型の入口になります。

素人目線メモ

「なんかいい」は、美術の感想として弱い言葉だと思っていました。でも、そこから「何がいい？」と一個だけ掘れば、ちゃんと観察になります。自分にとっては、感想を否定せずに次へ進める型です。

2. 「なんかいい」を4つに分ける

最初の印象を、色・形・配置・リズムの四つのどれかに分けます。「色が好き」「丸い形が気になる」「左右の余白が気持ちいい」「同じ形の繰り返しが心地いい」。専門用語は要りません。

入口見ること
色一番強い色は？ 隣の色で印象が変わる？
形丸・四角・線など、どの形が多い？
配置中央に集まる？ 端まで広がる？ 余白は？
リズム同じ形や色がどんな間隔で繰り返す？

「なぜ好きか」を説明できなくても、どこに目が止まったかまで言えれば十分です。自分の反応の原因を画面に戻して探すことが、5の型の鑑賞になります。

3. 抽象作品でも「見る場所」はある

何が描かれているかわからない抽象作品は、1の型だと入りにくいことがあります。でも5の型なら、何かの形に見立てる必要がありません。一番強い色を見つけ、そこから同じ色を追う。大きな形と小さな形を比べる。線の方向を追う。それだけで画面に滞在できます。

「これは何を表しているの？」を一度外すと、絵が少し音楽に近く感じられることもあります。意味より、強弱や反復、間を感じる。もちろん意味がある作品もありますが、最初の入口として視覚だけを使うのは十分ありです。

4. 少し知ると見え方がどう変わる？

構成、抽象、形式といった言葉を知ると、「なんかいい」を説明しやすくなります。構成は配置、抽象は現実の形をそのまま再現しないこと、形式は色や形、素材など作品を成り立たせる要素。難しい定義より、自分が見たものに後から名前を足すくらいで十分です。

また、同じ画家の別作品を見ると、「この色の組み合わせを何度も使う」「いつも画面全体に形を散らす」と特徴が見えてきます。5の型は、画家ごとの見方とも相性がいいです。

5. 実物では何を見る？

画像では色が端末によって変わり、大きさも均一になります。実物では、まず少し離れて色面や配置を全体で受け取り、その後に近づいて表面を見る。大きな作品なら、自分の視野に入りきるかどうかも大事です。

3秒で「なんかいい」を決める

理由は考えず、最初に反応したところを覚える。

一要素だけ選ぶ

色・形・配置・リズムから一つ。

画面全体で繰り返しを探す

同じ色や形がどこに戻ってくるか追う。

離れてもう一度見る

細部を見た後、最初の印象が変わったか確認する。

実物で「思ったより色が鈍い」「思ったより巨大」「絵の具が厚い」と気づけば、それも見た目の体験です。作品写真との違いを一つ持ち帰ると記憶に残ります。

6. 6の型との境目

5の型で見ていると、「この形、気持ちいい。でもなぜこの形なんだろう？」と問いが生まれることがあります。そこから6の型「なぞなぞ系」へ移ればいい。逆に、難しいコンセプト作品でも、まず色や形だけを楽しんでから考える方法もあります。

「見た目だけで楽しんだら浅い」ということはありません。見た目が入口になり、その後に意味や背景へ進む。その順番の方が自分には作品が残りやすいです。

素人目線メモ

現代アートの前で「なんかいい」と思えたら、それを打ち消さない。まず一回その感覚を信じて、どこがいいか一つ探す。それだけで十分鑑賞になっています。

「きれい」と感じる作品だけが5の型ではありません。妙に不安定、落ち着かない、目がチカチカする、といった視覚的な反応も入口です。快・不快を決める前に、どの色や形、間隔がその感覚を作っているのかを探すと、「なんか変」が具体的な観察に変わります。

今日の合言葉

意味より先に、「なんかいい」。
