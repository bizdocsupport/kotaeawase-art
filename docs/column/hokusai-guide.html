ARTIST GUIDE画家を知る #03

葛飾北斎の絵はどこを見る？｜形・大きさ・動きを見る

北斎は見た景色をそのまま切り取るより、富士や波を使って一枚の画面を強く組み立てるところを見ると面白くなります。

先に結論

北斎は「何を描いた？」より「どんな形で画面を作った？」を見る。大・中・小、動く形・動かない形を比べる。

この記事の目次
  1. まず形
  2. 大きさ
  3. 反復
  4. 動きと静けさ
  5. 小さな人
  6. 広重と比べる

北斎は題材の面白さだけでも楽しめますが、画面の形を意識するとさらに見やすくなります。大きな波、小さな富士、曲がる人物。まず「一番大きい形は何？」と探すだけで、北斎が画面をどう組み立てたかが見え始めます。

1. 細部より先に大きな形を見る

波なら曲線、富士なら三角形、舟なら細長い形。題材の名前を確認したあと、一度シルエットとして見ると北斎の構図が分かりやすくなります。

「上手に描いた波」ではなく、「画面に巨大な曲線を置いた」と考えるだけで印象が変わります。

北斎は、複雑な自然をそのまま写すより、見た瞬間に伝わる強い形へ整理するのが得意です。波の弧、富士の三角、橋の直線など、まず黒いシルエットにしたつもりで見ると、画面の骨組みがはっきりします。

細部の巧さはそのあとで十分です。最初に「一番大きな形は何？」「次に大きい形は？」と二つだけ比べると、北斎がどこへ迫力を集めたかが分かりやすくなります。

2. 実際の大きさではなく、画面の中の大きさを比べる

《神奈川沖浪裏》では、本当は巨大な富士が小さく、目の前の波が富士よりはるかに大きく描かれています。

この差が遠近感と迫力を同時に作ります。波・舟・富士を大・中・小として見るのが簡単です。

現実の大きさと、画面の中で占める大きさは別です。遠い富士は小さく、目の前の波は大きい。この当たり前の遠近の差を、北斎は極端なくらい強く使うことで、普通の風景以上のドラマを作ります。

美術館では、親指で隠せそうな富士と、画面の大部分を占める波を交互に見てください。「日本一高い山がこんなに小さい」という逆転に気づくと、一枚の中の距離が急に大きく感じられます。

3. 同じような形がどこに繰り返されるか

大波の先、小さな波、白いしぶきには似た曲線や爪のような形が何度も出てきます。

一つの波として見るより、同じ形の反復を追うと画面全体がリズムを持って動いて見えます。

反復を見るときは、完全に同じ形を探す必要はありません。大きな波の先端、小さな波の泡、富士の斜面など、「似た角度」「似た曲がり方」を探すだけで、画面の中に韻のようなつながりが見えます。

自然の形は本来ばらばらですが、絵の中では作者が選び直しています。同じような形が複数あると気づくと、北斎の画面が偶然の景色ではなく、かなり計算された構成であることが見えてきます。

4. 激しい動きの中の「動かないもの」を探す

波と舟は斜めに動きますが、遠くの富士は静かな三角形として座っています。

動くものだけでなく、動かない形を見ると、周囲の激しさがさらに強く感じられます。

素人目線メモ

以前は《神奈川沖浪裏》を「有名な波の絵」としか見ていませんでした。富士が驚くほど小さいと気づいたとき、構図を見る面白さが急に分かりました。

動きは、激しい物だけを追うと疲れてしまいます。そこで一つ、ほとんど動かない形を決めます。《神奈川沖浪裏》なら遠い富士。そこへ何度か視線を戻すと、波と舟の斜めの動きが以前より強く感じられます。

「静かな基準」があるから「動き」が分かる、という見方です。画面の中で一番安定している形と、一番不安定な形を一つずつ選ぶだけでも、構図の緊張が見えてきます。

5. 小さな人物は景色の尺度になる

北斎の風景では人物が小さくても、人がいることで波や山の大きさを身体感覚で想像できます。

舟に伏せる人、道を歩く人の姿勢を見ると、景色がただの模様ではなく人が生きる場所になります。

北斎の小さな人物は、単なる飾りではありません。舟に身体を伏せる人、坂を登る人、荷を担ぐ人など、姿勢が周囲の傾きや風の強さと呼応しています。人を見ると自然の力が身体の感覚へ翻訳されます。

また、人物の小ささは景色の大きさを強めます。波や山だけでは抽象的な「大きい」ですが、人間と比べた瞬間に「自分ならどう感じるか」へ変わります。

6. 広重と並べると「形」の強さが見える

単純化はできませんが、入口として北斎＝形、広重＝場所と置くと比較しやすくなります。

北斎は波や富士を画面の骨格へ。広重は手前・遠景・雨や雪によって、その場に立つ感覚を作る。並べるほど違いが見えてきます。

北斎と広重を「北斎は派手、広重は静か」とだけ分ける必要はありません。比較するときは、まず同じ富士や旅の場面で「画面の骨格を何が作っているか」を見ます。北斎は大きな形や反復が前に出る作品が多く、広重は視点や天候、距離の層が場所の感覚を作る作品が多い、と置くと整理しやすいです。

もちろん二人とも多様な作品を残しているので、これは入口の見方です。それでも並べて見ると、同じ日本の風景が「形を組み立てる面白さ」と「その場に立つ面白さ」に分かれて見える瞬間があります。

今日の合言葉

北斎は「何を描いた？」より「どんな形で画面を作った？」を見る。大・中・小、動く形・動かない形を比べる。
