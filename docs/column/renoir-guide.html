ルノワールの絵はどこを見る？｜光より「影の色」を見る

ルノワールは「明るくて楽しそう」で終わりやすい画家です。そこから一歩進めるなら、光が当たっていない影の中の色を探します。

先に結論

ルノワールは明るい場所より影の色を見る。青・紫・緑が肌や服にどう混ざるかを探す。

この記事の目次
  1. 影
  2. 肌
  3. 木漏れ日
  4. 人
  5. 筆触
  6. 全体

ルノワールは明るく華やかなので、「楽しそう」「肌がきれい」で満足しやすい画家です。そこから一歩だけ進めるなら、明るい場所ではなく影を見ます。影の中に青や紫を見つけると、画面の色が急に増えて見えてきます。

1. 最初に「影」を見る

明るい肌や華やかな服より先に、木陰や服の影に青・紫・緑がないか探します。

暗い＝黒ではないと気づくと、画面の色が急に増えて見えます。

影を見るときは「暗い場所」を探すより、明るい部分のすぐ隣を見る方が簡単です。頬の下、帽子の影、白い服のしわなどには、黒ではなく青や紫、少し緑がかった色が置かれることがあります。明るい場面なのに画面が単調にならない理由がここにあります。

少し離れて見ると、それらの色は「青い影」として主張するのではなく、自然な陰影へまとまります。近くでは意外な色、離れると柔らかな光。この二つが同時に成り立つところを確かめると、ルノワールの色の使い方が具体的に見えてきます。

2. 「肌色」という一色を探さない

顔や腕にはピンクや黄だけでなく、青や紫の筆触が混ざることがあります。

近くでは別々の色なのに、離れると柔らかな肌としてまとまります。

素人目線メモ

ルノワールを見て「肌がきれい」で終わっていた頃は、影をほとんど見ていませんでした。影に青や紫を探すようになってから、人物が色の集まりとして見える瞬間が増えました。

人物画では、顔を「肌色」で塗った面として見るのではなく、小さな色の集まりとして見ます。額、頬、鼻、首では光の向きが違うので、暖かい色と冷たい色が少しずつ入れ替わります。輪郭線より色の変化で顔が立ち上がっている場所もあります。

実物では、顔を近くで見すぎると表情が崩れて色の跡に見えることがあります。そこから一歩下がって、どの距離で「人の顔」に戻るかを見るのがおすすめです。人物を写実的に描くことと、細部を細密に描くことが同じではないと分かります。

3. 木漏れ日は画面の道しるべ

《ムーラン・ド・ラ・ギャレットの舞踏会》では、木漏れ日が顔、服、地面へ細かく落ちています。

同じ光を追うと、目が画面のあちこちへ動き、人が動き会話しているようなざわめきが生まれます。

木漏れ日は、丸い白い点を散らしただけではありません。顔や服の形に沿って光の形が少し変わり、地面ではまた別の模様になります。光が同じ場所から来ていても、当たる物によって見え方が変わるところまで追うと、場面の立体感が増します。

また、光の斑点は人物同士をつなぐ役目もします。一人の肩にある明るい点から、隣の帽子、さらに奥の服へと同じ明るさを探すと、混雑した画面の中に視線の道ができます。

4. 人物を小さなグループで見る

踊る二人、座って話す人、こちらを見る人。一人ずつではなく小さな集まりとして見ると、人混みが整理されます。

誰が誰を見ているかを追うと、画面全体に会話のつながりができます。

人混みは、全員の名前や関係を知ろうとすると急に難しくなります。まず二人か三人だけを一つの島として見ると、身体の向き、距離、手の位置から「会話している」「踊っている」「こちらへ意識が向いている」といった関係が自然に読めます。

その小さな島を一つずつ隣へ移していくと、画面全体がばらばらな人物の集合ではなく、いくつもの会話が重なった場所に変わります。ルノワールの楽しさは、笑顔の多さより、この人と人の近さにもあります。

5. 近くでは輪郭がかなり曖昧

顔や服を近くで見ると、細密な線より筆触と色の重なりが目立ちます。

少し離れると、その色の集まりが人物や光へ変わります。

輪郭が曖昧なのは、描けなかったからではなく、光の中で形が溶ける見え方を残しているからです。袖と背景、髪と帽子、頬と影の境目など、どこまでが人物か一瞬分からなくなる場所を探してみてください。

反対に、目や帽子の縁など、必要な場所だけ少し強く置かれていることもあります。全部を同じ細かさで描かず、見せたいところと溶かすところに差をつけることで、画面に呼吸のような強弱が生まれます。

6. 最後に全体へ戻る

一人、光、影、グループと見たあと、少し離れて全体を見ます。

最初は混雑して見えた画面が、人と光がリズムよく繰り返される一つの場所として見えてきます。

最後に全体を見るときは、「楽しそう」という印象を一度言葉にしてから、その理由を画面の中で探します。暖かい色が多いのか、人の距離が近いのか、斜めの姿勢が多いのか、木漏れ日が散っているのか。印象を構成要素へ戻すと、自分が何に反応したのか分かります。

ルノワールは人物を一人ずつ鑑賞しても楽しめますが、少し離れて「光と人のリズム」として見ると別の作品に見えます。細部と全体を行き来できることが、実物鑑賞の大きな面白さです。

今日の合言葉

ルノワールは明るい場所より影の色を見る。青・紫・緑が肌や服にどう混ざるかを探す。
