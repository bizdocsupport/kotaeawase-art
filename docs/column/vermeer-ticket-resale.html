2. 追加抽選は「先着」ではない

追加抽選も抽選制です。受付開始時刻ぴったりにアクセスした人から席が埋まる仕組みではありません。

一般抽選では第5希望まで申し込める仕組みが用意されていました。希望時間に幅を持たせられるなら、一つの時間だけに絞らない方が候補を増やせます。最新の申込条件は各追加抽選の受付画面で確認してください。

3. もう一つの方法｜チケットぴあ公式リセール

当選したものの行けなくなった人が出品できるチケットぴあ公式リセールもあります。

公式案内では、リセール期間は2026年7月31日12:00から、各チケットの来場日前日23:59まで。ただし、対象となる販売方法・チケットには条件があります。

リセールは「この日に必ずまとまった枚数が追加される」というものではありません。出品があったときに初めて購入機会が生まれるため、抽選とは性格が違います。

4. 当日、美術館へ行けば買える？

ここは注意です。

展覧会公式は、大阪中之島美術館で一般向け当日券を販売しないと案内しています。

「キャンセルがあるかもしれないから、とりあえず現地へ」という狙い方はできません。追加抽選または公式リセールなど、公式に案内された方法を使う必要があります。

5. 「非公式の転売」ではなく公式ルートだけを見る

人気展なので、SNSやフリマ等でチケットの話を見かけることもあるかもしれません。

ただし、チケットの有効性や本人確認、トラブルの可能性を考えると、ここでは展覧会公式が案内する販売・リセールだけを追うのが安全です。

更新型の記事です抽選日程・販売方法は変更される可能性があります。このページは2026年8月18日時点。申し込み前に必ず公式チケットページで最新情報を確認してください。
